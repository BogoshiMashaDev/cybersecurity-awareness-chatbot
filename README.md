# 🔐 Cybersecurity Awareness Chatbot

## Overview

The Cybersecurity Awareness Chatbot is a Windows desktop application developed using C# and .NET Windows Forms. The application is designed to educate users about cybersecurity best practices through an interactive chatbot experience.

This project was completed as part of my Bachelor of Computer and Information Sciences in Application Development at Emeris (formerly Varsity College).

---

## Features

- Interactive chatbot
- Cybersecurity awareness education
- Password security tips
- Quiz system
- Task management
- Activity logging
- User memory
- Input validation
- Audio greeting
- Object-Oriented Programming implementation
