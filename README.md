# Cybersecurity Awareness Chatbot

## Overview

The Cybersecurity Awareness Chatbot is a C# Windows Forms application developed for PROG6221. The chatbot educates users on cybersecurity topics through interactive conversations and additional features such as task management and quizzes.

---

## Features

### Part 1

* Voice greeting using WAV audio.
* ASCII art and formatted interface.
* User interaction and personalized responses.
* Basic cybersecurity advice.
* Input validation.

### Part 2

* Windows Forms graphical user interface.
* Keyword recognition.
* Randomized responses.
* Memory and recall.
* Sentiment detection.
* Conversation flow.

### Part 3

* Task assistant with MySQL database integration.
* Reminders for cybersecurity tasks.
* Cybersecurity quiz game.
* Natural language processing simulation.
* Activity log tracking.
* Personalized interactions.

---

## Installation

1. Clone the repository.
2. Open the solution in Visual Studio 2022.
3. Install the MySql.Data NuGet package.
4. Create the MySQL database named:

```
cybersecuritybot
```

5. Create the Tasks table.
6. Run the application.

---

## Example Commands

* My name is Manong
* I am worried about phishing
* Tell me about password safety
